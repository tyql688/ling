Electron Builder reads the platform packaging assets referenced by `apps/desktop/electron-builder.yml` from this directory:

- `icon.icns` — macOS app icon
- `icon.ico` — Windows app icon
- `icon.png` — Linux app icon (512x512)
- `dmg-background.png` and `dmg-background@2x.png` — macOS disk image background at standard and Retina resolutions
